# 2.1 — Instalación de Ubuntu Server

## Objetivo
Instalar Ubuntu server en HPE PROLIANT MICROSERVER Gen10 para establecer una base del entorno en nuestra infrestructura.

## Entorno

- Servidor: HPE ProLiant MicroServer Gen10
- CPU: AMD Opteron X3421
- RAM: 4 GB DDR4 ECC UDIMM
- Almacenamiento: Toshiba ~1 TB
- Sistema operativo: Ubuntu Server 26.04.1 LTS
- Arquitectura: AMD64
- Medio de instalación: USB booteable

## Estado

**Instalación completada correctamente.**
